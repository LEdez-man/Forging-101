Almost every forging can be broken down into a small number of basic operations. In manufacturing terms, hand forging is **open-die forging** (DIN 8583-3, compressive forming). The workpiece is shaped between hammer and anvil without a closed die. Some operations use separating processes (hot cutting, splitting, punching). See DIN 8580 for the classification.

| Operation | What happens | Main tool | Article |
|---|---|---|---|
| Drawing out | section ↓, length ↑ | face, horn, cross-peen | [[en/techniques/drawing-out\|Drawing out]] |
| Spreading | width ↑, thickness ↓ | peen lengthwise, face | [[en/techniques/spreading\|Spreading]] |
| Upsetting | length ↓, section ↑ | face, upsetting block | [[en/techniques/upsetting\|Upsetting]] |
| Tapering | section runs out to the end | face, angled blow | [[en/techniques/tapering\|Tapering]] |
| Shouldering | step in section with a shoulder | anvil edge, set hammer | [[en/techniques/shouldering\|Shouldering]] |
| Fullering | groove / neck, displace material | fuller | [[en/techniques/fullering\|Fullering]] |
| Splitting | divide the bar lengthwise | hot chisel | [[en/techniques/splitting\|Splitting]] |
| Punching / slitting / drifting | make and open a hole | punch, slitter, drift | [[en/techniques/punching\|Punching]] |
| Hot cutting | cut off | hardy, hot cut | [[en/techniques/cutting\|Hot cutting]] |
| Bending | change direction, eyes, scrolls | anvil edge, horn, bending fork | [[en/techniques/bending\|Bending]] |
| Twisting | rotate about the long axis | vise, twisting wrench | [[en/techniques/twisting\|Twisting]] |

> [!tip] Teaching order
> A proven order: **hammer control → drawing out → tapering → bending → upsetting → shouldering → punching/splitting → twisting.** Mark Aspery's CBA Level I curriculum and Black Bear Forge's "Back to Basics" series follow the same logic: first controlled material flow, then separating and joining. → [[en/projects/learning-path|Learning path with exercise pieces]]
