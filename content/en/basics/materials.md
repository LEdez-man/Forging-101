## Which steel for what?
| Material (EN / no.) | Approx. equivalent | Carbon | Hardenable | Typical use |
|---|---|---|---|---|
| **S235JR** (1.0038) | A36 / 1018 | ≤ 0.2 % | no | Practice pieces, decorative work, grilles, hooks |
| **C45** (1.0503) | 1045 | 0.45 % | yes (water/oil) | Punches, drifts, hammers, swages |
| **51CrV4** (1.8159) | 6150 | 0.5 % | yes (oil) | Vehicle springs; chisels, punches, knives |
| **C60 / C75** | 1060 / 1075 | 0.6–0.75 % | yes | Blades, axe bits |
| **1.2510** (100MnCrW4) | O1 | 0.95 % | yes (oil) | Knives, tools |
| **1.2842** (90MnCrV8) | O2 | 0.9 % | yes (oil) | Knives, pattern welding (with nickel steel) |
| **1.1274** (C100S) | 1095 | 1.0 % | yes (water / fast oil) | Blades, pattern welding |
| **75Ni8** (1.5634) | 15N20 | 0.75 % + 2 % Ni | yes | Bright layer in pattern welding |
| **Wrought iron** | — | ~0 % (slag fibres) | no | Historic restoration; welds superbly |

**Beginners:** S235/A36 in 10–16 mm (⅜–⅝") square and round is cheap, forgiving and suits all [[en/techniques/index|basic techniques]]. Build your tools (punches, chisels) afterwards from 1045 or 5160/51CrV4.

## Salvaged steel
Springs, files, bearing races, jackhammer bits and rail are popular sources. Their alloy is unknown, so test first:
1. **Spark test** on the grinder: more branched sparks mean more carbon (see [Black Bear Forge – Spark testing steel](https://www.youtube.com/watch?v=gbPSYxexZYU)).
2. **Test hardening:** harden a sample and check whether a file bites (see [Black Bear Forge – Test hardening unknown steels](https://www.youtube.com/watch?v=rkEoh1J143k)).
3. **Coatings:** remove zinc, chrome and paint first (→ [[en/basics/safety|Safety]]).

## Scale
Heating forms **scale** (iron oxide), about 1–3 % loss per heat. Scale on the face gets hammered into the work as pits, so brush or blow face and work regularly. A few drops of water on the face blast the scale off with the next blow.
